# Constitución - Im Chic by Mel

1. **Diseño Mobile-First:** Toda interfaz debe estar optimizada y probada para pantallas móviles antes de adaptarse a escritorio.
2. **Estabilidad Estructural:** Prohibido modificar, eliminar o sobrescribir componentes existentes (como la Navbar o TurnoModal) mediante programación por intuición. Todo cambio profundo requiere una especificación (spec) y planificación previa.
3. **Estética Consistente:** Respetar estrictamente la identidad visual de la marca y usar exclusivamente las clases utilitarias de Tailwind, salvo excepción autorizada por el usuario: se permite el uso de `styled-components` en componentes de UI custom cuando él lo solicite explícitamente.
4. **Validación Visual:** Ninguna tarea se da por terminada sin comprobar que la interfaz responde correctamente a la interacción del usuario.
5. **Prevalencia de SDD:** Las reglas de este documento y las especificaciones de la carpeta "specs/" mandan sobre cualquier instrucción rápida o ambigua.
