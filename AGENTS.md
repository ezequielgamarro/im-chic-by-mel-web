## Stack y Comandos
- React 19, Vite SPA, Tailwind (vía CDN).
- Comandos operativos: npm install, npm run dev, npm run build.

## Flujo de Trabajo SDD (Spec-Driven Development)
- Prohibido modificar código al azar.
- Todo desarrollo debe iniciar leyendo docs/constitution.md.
- Para nuevas funcionalidades, debes generar una especificación en la carpeta specs/ y redactar un plan.md antes de alterar cualquier archivo .jsx.

## Memoria
- Lee MEMORY.md al iniciar sesión. 
- Al finalizar tareas, actualízalo documentando el estado actual y las decisiones arquitectónicas (límite: 50 líneas).
